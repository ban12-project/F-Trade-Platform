# Browser Agent 调优记录（2026-11-04）

关联 Issue #819 / PR #820。使用平台数据库默认模型，不更改账号、授权、校验器或部署。

## 检索资料与适配

- [Anthropic：Building effective agents](https://www.anthropic.com/research/building-effective-agents)：根据环境反馈评估进展，保留停止条件，优先简单且可检查的结构。采用操作反馈，不增加新的 Agent 框架。
- [Browser Use：All Parameters](https://docs.browser-use.com/open-source/customize/agent/all-parameters)：支持有限步骤历史、步骤超时和失败限制。这里保留最近六步的动作类别和页面是否变化，不记录正文、凭据、完整页面或模型思考。
- [Browser Use：Prompting Guide](https://docs.browser-use.com/open-source/customize/agent/prompting-guide)：明确任务和动作名称。这里为各操作定义可观察完成条件，解释 read 仅刷新快照，不代表提取消息；完成后调用 finish，由独立校验器判断成功。

以上为设计依据，不是本项目效果证据，也没有引入 Browser Use 依赖。

## 问题和变更

旧版每轮只给当前快照，缺少上一步动作反馈。登录提示要求填密码后登录，却未明确 authenticated 后停止；收件提示要求读取消息，但原型实际上由宿主验证器读取，read 工具只刷新观察。这种任务与工具语义不匹配会误导模型反复尝试。旧评测不能直接归纳为模型无法处理浏览器操作。

此次同时调整任务说明和运行时反馈：最近六步的动作类别、是否改变观察、无进展计数及剩余调用预算。反馈仅是执行记录，不是成功证明。不自动替模型触发 finish、不把验证结果提前作为答案、不改变三次无进展／40 次调用／五分钟上限。

页面、故障注入、验证函数、固定脚本基线、模型名称和并发保持相同，完整重跑十次矩阵；旧报告保留。本次没有消融实验，因此不能区分提示词与历史反馈各自的贡献。数据集已经用于调优，改善只证明在此集合上的拟合，不证明对新网站或未知页面的泛化。

## 完整复测结果

使用同一数据库模型名 gpt-6.1-terra、相同页面与判定代码、8 个独立 context 并发。1080 行全部通过：540 个 Agent 用例和 540 个固定脚本用例。六项均为 limited-pass，未宣称生产可用。调优前为 980/1080 通过，100 个 Agent 用例因无进展停止而失败。

| 操作 | 调优前正常及变化场景通过数 | 调优后通过数 | 中位耗时（前 → 后，秒） |
| --- | --- | --- | --- |
| 登录 | 5/40 | 40/40 | 13.731 → 7.162 |
| 页面检查 | 35/40 | 40/40 | 4.768 → 2.231 |
| 文字发布 | 40/40 | 40/40 | 5.136 → 5.144 |
| 图片发布 | 40/40 | 40/40 | 7.556 → 7.968 |
| 视频发布 | 40/40 | 40/40 | 7.590 → 7.512 |
| 收件观察 | 0/40 | 40/40 | 9.577 → 5.452 |

正常页及位置、标签、加载变化的每组均为 10/10。预期拒绝用例没有失败，每个用例最多一次提交。普通场景的停止后人工处理需求降为 0/40，但这不是实际生产人工接管率。模型调用总数 1326 → 1070（约减少 19.3%）。部分发布任务输入 token 上升，文字／图片耗时未改善；没有已审核单价，费用仍为 null。

[可复核统计摘要](browser-agent-tuning-summary.json)记录每项调用量、token、耗时、模型及报告摘要。完整脱敏报告位于本地 test-results/browser-agent-tuned-20261104/report.json。运行时 HEAD 为 e225225，调优代码尚未提交，实际源文件摘要为 12bc1f7a883cb69e268580a9ede6f277979235c36a9105bd2d8cdaacb8a04a13；未删除旧批次、未筛选失败重跑。

这些结果支持“显式完成条件与有限反馈改善当前原型”，不支持“全面替代已可用”。独立验证器仍承担收件读取与身份判定；图片视频使用合成字节；生产驱动配对、实际媒体、Camoufox 环境一致性、未见过的页面和独立留出集都未验收。下一步应先增加留出用例，再扩大宿主能力，不能直接部署。
