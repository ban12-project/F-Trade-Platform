# Browser Agent 隔离原型验收（2026-11-04）

后续互联网资料调优与复测见 [调优报告](browser-agent-tuning.md)；以下数据库结果保留为调优前基线。

研发跟踪：Issue #819。结论：**原型契约通过，真实模型评测不支持全面替代**。本报告不批准生产部署。

## 已实现的边界

`lib/browser-agent` 提供模型决策循环、运行时 Zod 校验和显式选择的发布准备驱动。模型通过现有 `createProductAgentModel` 接入，输出结构化命令。默认选择 legacy，生产 browser-node 不接入实验驱动。现有发布执行器继续负责提交前后校验和 unknown 结果；合成驱动额外验证受众并锁定单次提交。

命令只能引用宿主提供的能力、内容或凭据引用，不能携带任意选择器、URL、文件路径、脚本或正文。发布按钮没有普通点击能力。模型观察不含密码值，审计仅包含动作类别及观察摘要。每次模型决策计入 40 次预算，观察和验证也受五分钟取消信号约束；连续三次观察没有变化停止。未知错误不写原始异常。

能力接口允许受限导航和滚动，但当前合成任务没有注册这两类能力；不能据此宣称已经验收导航或滚动。宿主适配器必须自己保证目标映射、效果授权和取消执行；通用循环无法证明一个恶意宿主提供的能力安全。超时 Promise race 不等于撤销远端效果。

## 可重复运行

- `pnpm test:browser-agent`：独立证据、权限拒绝、无进展、调用上限、模型超时、租约取消、凭据不进入观察及禁止重复提交。
- `pnpm eval:browser-agent --contract-only`：108 个脚本驱动的合成契约用例；不是 AI 成功率。
- `pnpm eval:browser-agent --config /private/model.json --output test-results/browser-agent-model`：每个组合、每种驱动重复十次。配置结构见 `evals/browser-agent/model.example.json`；密钥通过指定环境变量读取，不写配置和报告。
- `pnpm exec playwright test --config playwright.browser-agent.config.ts`：独立运行既有登录、发布与收件 DOM 回归。
- `node --env-file=.env --env-file=.env.local --import tsx scripts/eval-browser-agent.ts --database --output test-results/browser-agent-database-NEW`：只读加载平台数据库默认模型；可用 `--model-config-id` 选择已保存配置。读取、解密仅在内存中进行，随后关闭数据库连接。整个批次复用同一配置快照；不导出 API key、headers 或地址。数据库名称不是不可变供应商版本证明。
- `--concurrency` 默认 4，范围 1–8；各用例使用独立浏览器 context。每个用例完成后写入脱敏 `progress.jsonl`，保留中断证据；输出目录不能复用已有批次。
- 不提供配置时仍运行固定脚本基线，Agent 行标为 blocked，退出码 2；实际失败退出码 1。输出目录必须被 Git 忽略。

评测记录代码摘要、Git 修订、请求模型、声明版本及响应模型 ID。声明版本是操作者输入，不是供应商版本锁定证明；必须使用供应商支持的不可变模型标识才能建立可重复版本基线。费用仅在提供输入、输出每百万 token 美元单价且用量完整时估算，否则为 null，不假装免费。当前用量覆盖 Agent 准备循环。

## 已验证与尚未验证

108 个合成契约组合通过。独立运行时测试 7 项通过。未配置模型的正式矩阵执行了 540 个固定脚本基线用例，全部通过；54 组 Agent 组合明确标为 blocked，进程按契约退出码 2。类型检查通过，仓库 Biome 检查退出码 0（既有 234 条 warning、34 条 info）。受控发布、签名发布回执和视频发布策略回归通过。既有登录、发布、收件 DOM 回归 192 项全部通过（3.1 分钟）。正常页与位置、标签、加载变化均进入矩阵；覆盖登录挑战、身份错误、受众变化、附件不符、过期授权、提示注入、回执丢失与租约取消。模型超时和重复提交由独立契约测试覆盖。

这些证据只证明原型的受限工具与合成流程。初次交付缺少明确配置的真实模型，因此当时六项业务均标为 blocked。用户随后指定复用平台数据库配置；后续批次使用默认的 openai-compatible / gpt-6.1-terra，结果见后续真实模型记录。不能用脚本模拟填补真实模型验收。即使配置模型后达到 9/10，当前实现也最多返回 limited-pass：

| 项目 | 当前范围 | 完整验收缺口 |
| --- | --- | --- |
| 登录 | 合成密码注入及挑战停止 | 原有登录恢复流程、TOTP、真实运行时一致性 |
| 页面检查 | 合成身份检查 | 现有页面审核与生产 DOM 适配 |
| 文字发布 | 复用发布执行器的合成单次发布 | 与现有 Facebook DOM 驱动逐项配对 |
| 图片、视频 | 合成附件字节及摘要 | 真实格式、解码、上传行为与媒体回执 |
| 收件 | 合成入站稳定 ID、重复扫描去重 | 现有 inbox 驱动、数据库去重与签名入库 |

固定脚本基线是新建合成页面的确定性操作，**不是现有 Facebook 驱动的替代基线**。合成浏览器使用 Playwright Chromium、全网络阻断，没有生产 profile、代理、租约服务、签名回执服务或 Camoufox 镜像。没有触发真实账号、外部发布、私信或部署。

后续要完成原计划，仍需接入已有驱动使用的合成页面与浏览器传输，建立同一任务的旧驱动／Agent 配对；核对实际浏览器镜像；扩大登录与收件宿主适配；运行固定真实模型十次矩阵。当前不删除原有脚本，不建议全面替代。

## Decision / Risk

采用“模型操作、宿主独立核验”边界。模型自述完成不能作为工程事实、业务成功或回执证据。身份、授权、内容摘要与回执规则继续由确定性代码控制。页面提示属于不可信输入；是否能安全提供通用点击必须由目标能力映射证明，不能只依赖提示词。

创意审查不适用：此次只增加基础设施及显式 SYNTHETIC 测试内容，不改变营销创意、素材、字幕或创意生成提示词。研发 Issue / PR 不记录真实业务数据。

普通场景 Agent 用例端到端中位耗时按上述顺序为 13.731、4.768、5.136、7.556、7.590、9.577 秒。工具调用、输入输出 token 数见统计摘要。数据库未提供审核过的单价，费用保留 null，不能据此判断成本可接受。所有预期拒绝用例均正确阻断；每个用例最大提交次数为 1。提示注入用例中登录和收件仍有任务完成失败，但未观察到越权发布。现有断言不能证明所有形式的凭据泄露或所有提示注入均不可能。

结论只针对本次模型、提示词和能力设计：当前不应全量替换。后续应先改进任务完成条件与模型观察信息，再固定新版本重新跑独立批次；发布三项也必须补齐原驱动配对、真实媒体和 Camoufox 一致性，才能进入后续验收。
