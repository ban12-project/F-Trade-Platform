# 按需 Browser Sandbox 迁移（#332）

用户于 2026-09-08 明确要求：Browser Sandbox 仅在需要时启动，不常驻。
本迁移延续 #322 / PR #323 的节点、账号与任务授权约束，最终验收暂缓。

## 生命周期契约

- 开启计算的触发仅为人工接管请求或已获授权且实际到期的业务任务。节点列表刷新、状态查询、保活与空队列轮询不得启动或恢复 Sandbox。
- 平台负责按需调度；不能把当前常驻 Agent 的空轮询直接搬进长期运行的 Sandbox。
- 任务完成、用户关闭接管、无用户连接超时或授权撤销后，停止浏览器，再停止整个 Sandbox。运行超时是兜底，不是正常回收机制。
- 没有任务时不得延长会话。并发启动、停止和恢复必须以数据库中的操作标识和状态串行协调；模糊结果先查已有实例，不能创建替代实例并丢弃旧状态。
- 账号独立的 profile 必须在停止前一致落盘；恢复要重启 Docker 和 Agent，旧租约按现有恢复协议终止或确认，不恢复未知发布尝试。
- 列表状态只能使用不恢复会话的 SDK 元数据读取。不能调用可能自动恢复的 runCommand/fs 来探测一个已停止实例。
- 保留固定代理和出口校验、一次性接管票据及 WebSocket 到期撤销。没有账号授权或有效平台节点 Key 时，不启动真实账号运行。
- 停止计算不等于零费用：持久化快照可能继续收取存储费用，保留与删除策略需明确。

## 当前验证范围

已在真实 Vercel Sandbox 的 Ubuntu 环境安装并启动 Docker，并成功执行无网络的 hello-world 容器；实例已删除。这证明 Docker 执行基础，不证明完整 worker 或真实账号可用。

`scripts/test-browser-sandbox-runtime.mts` 是显式执行的实时验证，不接入普通 CI 自动计费。它只上传已提交的运行代码和固定上游源码，构建镜像，运行现有合成镜像 smoke，再停止／恢复 Sandbox 校验合成卷标记，最后删除实例和测试快照。它不包含真实账号、代理密码或客户资料。

首轮验证暴露的兼容性差异：当前 SDK 按 name 标识持久实体；快照有效期最小一天；默认工作目录不能硬编码为旧 runtime 的目录。脚本使用已核实的 name、最小有效期和明确的归档路径。失败轮次不记为通过。

## 按需退出与整体停止（实现基础）

Agent 新增部署级 `BROWSER_NODE_ON_DEMAND=1`。连续成功领取到空队列且本地无运行任务时，默认 30 秒后关闭网关并退出。收到任务或发生领取错误会重置空闲计时；旧 VPS 默认模式不因空队列退出。按需部署必须使用不自动重启的 Agent 容器，不能套用 VPS 的 `unless-stopped` 重启策略。

`stopIdleBrowserSandboxSession` 接收固定的 SDK Session，而非会自动恢复的 Sandbox facade。它核对 sessionId 和 Agent 的节点标签，活动 Agent 不停止；已退出 Agent 会先清理该节点的容器、停止 Docker，再停止整个会话。清理失败也尝试停止计算，但返回未确认状态，不能据此清除旧租约或记为正常释放。旧会话回调不会停止新会话。

验证：5 项空闲策略/实际 Agent 子进程回归、6 项 session 停止/身份/失败分支回归及既有 65 项节点回归通过。实际 Agent 使用本机 HTTPS broker 和 Docker 协议夹具；没有真实账号。实时 `test-browser-sandbox-idle.mts` 在 Vercel 内安装 Docker，构造退出的无网络合成 Agent 容器，再调用真实回收函数；提供方确认 VM 已停止，重复检查保持相同 sessionId 且未恢复。测试实例已删除。类型与格式检查通过。

上述函数尚未接入平台调度，不能宣称生产 worker 已自动按需运行。仍需持久化操作记录、授权校验、唤醒入口与 HTTPS 接管集成。

## 持久化启停协调（2026-09-10）

`0034_browser_sandbox.sql` 与 `sandbox-lifecycle.ts` 新增数据库协调层。登记仅创建元数据；空队列或已撤销节点不启动。启动和停止先锁定同一 broker 节点，再写入唯一操作 ID。只有赢得操作的调用方可以在事务提交后派发云端操作。请求失败或超时保留原操作并进入 unknown，不能据此另建实例；恢复必须查询原实例后确认结果。

回收以已退出 Agent 的确切 sessionId 为前提。新任务即使在停止期间进入，也保留在原队列，等旧会话停止后再启动；旧操作的迟到结果不能覆盖新的操作。这些辅助函数只供服务端事务使用，调用方仍须校验用户／任务授权，不能直接作为 HTTP 或 Action 入口。

真实 PostgreSQL 回归覆盖 12 个并发启动及停止请求、空队列、旧回调、未知结果恢复、停止期间新增账号任务和撤销后拒绝启动。类型和迁移检查通过。这里没有派发 Workflow、调用 Vercel SDK 或保存节点密钥；生产接入仍未完成。

## 托管节点登记与密钥（2026-09-10）

管理命令新增 `create-sandbox`，经现有 Server Action 的身份检查和事务内会话／权限检查。当前入口要求显式 `BROWSER_SANDBOX_ENABLED=1`，自动派发完成前不要在生产启用。登记只分配一个浏览器的默认容量并创建停止状态记录，未提供公网网关时保存 null，不编造接管域名。

节点专用密钥以 AES-GCM 加密保存，使用现有部署密钥环，但以独立 `node-access` 用途和节点 ID 绑定，不能挪作账号密码或复制到其他节点。创建、查询和轮换均不向页面返回托管节点密钥；撤销清空密文并使旧密钥失效。创建、列表查询、轮换和撤销均未调用云端 SDK。真实数据库回归已验证上述授权、隔离和不启动行为；既有浏览器发布、登录及收件回归通过。

尚需实现云端运行配置、派发／恢复调度、网关地址回填、按需管理 UI 和 HTTPS 接管。这个入口不是已完成的生产部署。

## Sandbox 内启动配置（2026-09-10）

`compose.sandbox.yaml` 定义单个 Agent，明确 `restart: no`、禁止拉取镜像、空闲 30 秒退出，节点密钥使用只读文件挂载。Agent 带节点及操作标签，供平台识别对应会话。恢复逻辑因此改为只停止同时具有节点和任务标签的浏览器容器，避免把 Agent 自身当成遗留浏览器停止。

`start-sandbox.sh` 只在已授权且正在运行的 VM 内执行。它检查 root 所有的 0600 配置／密钥文件、节点及操作标识和不可变本地镜像 ID，通过文件锁串行启动。相同操作对应的 Agent 已退出时，不再次启动；不同操作遇到仍运行的 Agent 时要求协调，不能强制替换。脚本不删除 profile 卷。平台生成运行配置和实际调用该脚本的部分仍待接入。

实际 Agent 子进程的恢复过滤与空闲退出回归、会话停止回归共 11 项通过，既有 65 项节点回归通过；启动脚本语法通过检查。新增 Compose 配置验证随双架构镜像 CI 执行。以上尚不证明新启动脚本已在真实 Sandbox 中完成端到端运行。

## 实测发现的资源控制兼容问题（2026-09-10）

首次实际调用启动脚本失败：未初始化嵌套 cgroup 时，Docker 创建的层级进入 threaded 模式，带内存上限的 Agent 无法启动。无资源限制的 hello-world 通过不能证明此配置可用。失败实例已删除。

`prepare-sandbox-cgroups.sh` 采用 [Moby 的嵌套 cgroup 初始化方法](https://github.com/moby/moby/blob/master/hack/dind)，在专用 VM 的首个 Docker 容器之前把现有进程放入子 domain，并启用内存及线程控制器；没有移除容器限制，也不操作 VM 命名空间之外的层级。已经进入不兼容模式时拒绝继续。重试有次数上限，不能永久阻塞启动。

独立真实 Sandbox 探针已验证修复前限内存容器启动失败、初始化后相同配置成功，容器内核 `memory.max` 实际为 67108864（64 MiB）。探针实例均已删除。恢复时 cgroup 是新内核状态，必须在重启 Docker 前重新初始化，不能把文件系统快照当成已恢复资源控制配置。

`test-browser-sandbox-start.mts` 使用已提交 Agent 源码、空队列 HTTPS 合成 broker、临时节点 Key 和不可变本地测试镜像，实际执行启动脚本。它测试重复启动、Agent 空闲退出、HTTPS 接管静态资源及整机回收，不发放真实账号任务，不证明浏览器 profile、代理或 WebSocket 接管。

使用 `8b9bed1` 的完整合成实测通过：Agent 正常启动，容器内核内存上限为 536870912（512 MiB），重复调用返回 already-running，公开 HTTPS 地址可以访问 `/viewer`；空闲退出后同一操作返回 already-exited，没有重新启动。随后真实 session 回收函数停止整个 VM，元数据确认 stopped 且 sessionId 未变。最后删除实例和测试快照，清理完成后才写入成功结果。生产派发与实际业务接管仍未完成。
