# 参考资料说明

`目录总表.pdf` 是从现有汽配目录获得的格式参考，内容为制动盘/刹车片适配数据，不是第一阶段离合器产品数据。

## 可参考的结构

- 车型系列与车型型号
- 安装位置
- 工厂内部编号
- OE 编号
- 尺寸字段及单位
- 结构/配置布尔字段
- 配套刹车片编号

## 不可直接复用的内容

- 不把其中的制动盘、刹车片记录转成离合器产品。
- 不把其中的数值、车型、OE 或编号作为离合器测试 fixture。
- 不在 Content、RFQ 或报价流程中引用这份资料的工程事实。

PDF 已按原样归档，未编辑、未重排、未转码。第一阶段真实产品数据必须由工厂提供并通过 Product Human Gate。

## 真实目录的保管边界

未取得归档授权的真实离合器目录只能在受控本机或批准的 Private Blob 中处理，不能 `git add`、提交、上传到 Issue/PR 或作为 CI fixture。`repository-validate` 仅允许本目录中已登记的格式参考 PDF 被 Git 跟踪；真实目录即使已获本机处理授权，也仍应保留在受控存储中，仓库只记录脱敏引用和聚合结果。
