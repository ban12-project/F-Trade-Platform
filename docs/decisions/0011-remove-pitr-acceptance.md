# ADR 0011：移除 MVP1 数据库时间点恢复验收

状态：accepted（2026-11-01，用户明确删除需求）

关联研发 Issue：#746、#122、#32。

## 决定

用户明确要求：“删除 数据库时间点恢复（PITR）验收 需求 不需要做”。
数据库 PITR 演练及其恢复专用验收证据从 MVP1 范围中移除，不再作为
Go/No-Go 前置条件，也不再列为待授权或延期事项。该项状态是范围移除，
不是测试通过。后续 Agent 不应因历史报告缺少 PITR 证据而重新阻塞 MVP1。

未提交的 Neon 隔离分支创建表单已取消；没有创建恢复分支、执行恢复、
设置副本自动删除或修改生产数据库配置。现有供应商备份与恢复窗口配置
不因删除验收要求而关闭或调整。

## 保留的要求

90 天保留政策、到期访问阻断、真实到期对象与 Blob 删除、原始来源保护、
历史及供应商副本的保留与清除证据继续由 #122 跟踪。既有合成恢复回归可
继续保留，用于验证应用行为，但不新增生产 PITR 演练要求。

## 历史记录

历史报告保留当时的未执行和失败观察。当前验收清单与本决策优先于旧报告
中的 PITR 待办；不把未执行结果改写为通过，也不因此将 #122 整体结项。
