# ADR 0010：产品以最终事实审核验收

状态：accepted（2026-10-09，用户明确调整验收标准）

关联研发 Issue：#6、#268、#5。

## 决定

自动识别率衡量效率，允许漏读和误读。审核人可以对照原件补录或纠正，保存证据和修改记录。产品就绪必须以当前版本最终事实审核为准：关键字段完整、每个已填写事实有来源、Gate 01 审核通过；缺失或未确认的工程事实继续阻断。

验收政策升级为 v2.0.0。识别率、审核耗时和修订轮次单独报告，不再要求 100% 自动识别或最多修订一次。保留 A–D 各五个、共 20 个样本；正确阻断缺失事实是负例验收成功，该产品仍不是 ProductReady。

## 实现与边界

新验收结果显式选择政策版本并引用最终审核、来源清单和纠正审计。未版本化的历史结果仍使用 v1 校验，不追溯修改旧结果。来源期望错误只能新增有证据的版本化勘误。

应用原有 ProductReady 安全门保持有效。修订事务将字段改前、改后值和证据写入私有、只追加的审计记录，与产品版本和待审核记录一起提交；执行者和时间由服务端保存。拒绝、无权和并发失败的修订不产生成功修改历史。

自动抽取仍拒绝无来源、跨行或改写的工程事实；人工纠正必须重新选择证据并送审。本次委托审核如实记录为 Agent 在授权账户执行，不能冒充工厂独立签字。真实事实及原件不写入 GitHub。

## 后果

扫描资料的识别困难不再单独阻塞最终已核实产品；同时增加对人工修改可追溯性的要求。自动效率改进仍需验证来源保留和资源边界，但不以提高识别率为由推断单位、适配或安全性能。M1/M2 的其他生产验收仍需各自证据，不随本决策自动通过。
