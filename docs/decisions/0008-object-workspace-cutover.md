# ADR 0008：工作区按对象一次性切换

- 状态：Accepted，已实现；本地验收通过，最终 CI 为合并条件
- 日期：2026-09-30
- 关联：Decision #482、PR #483
- 取代：ADR 0005 的阶段导航，以及 ADR 0007 对历史阶段参数的兼容约定

## 决策

用户确认任务与资料为主入口，并授权业务与管理入口在一个版本完成切换。项目只管理归属、成员和归档。保留具体记录、创建与独立视频编辑器地址，新增项目管理列表。历史阶段参数显示停用提示，不解析或自动选择替代记录。

新建复用明确且有权限的归属上下文；没有明确归属时由用户选择。单条创建成功打开指定记录，批量导入保留结果清单。详情保留受校验的任务或资料列表返回地址。销售沿显式关联保留客户上下文；视频是可选内容形式。

发布进入具体内容或视频。账户、渠道与浏览器管理进入设置。只统一入口，不合并不同传输路径的授权、载荷、审核和回执协议。

## 边界与风险

不迁移数据库或业务状态，不更改记录 ID、成员、证据、审批和回执。任务始终是领域状态的读取投影。每个 Action 重新认证、授权并使用共享 Zod 校验。工程事实核验、报价与交期人工确认、逐帖确认、版本检查和失败闭合继续有效。

历史阶段书签会停用；所有仓库入口和测试夹具必须迁移。单条详情不应为解析阶段而读取全部可访问项目和业务记录。全局外壳、Cache Components、React Compiler、TypeScript 7 和默认 Turbopack 继续保留。

## 交付与验收

Issue → codex/482-workspace-simplification → PR → CI → squash merge。验收涵盖真实路由和隔离合成数据库、完整产品/内容/客户/视频旅程、权限/归档/版本、历史地址、桌面/390px、键盘、未保存保护、重复提交、即时导航、生产构建与回滚兼容。结果记录在工作区迁移验收文档；在证据完整前不标记完成。
