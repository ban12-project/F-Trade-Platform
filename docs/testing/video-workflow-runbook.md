# 视频工作流运行手册

## 边界

本手册适用于已录入且通过人工 Gate 01 的产品资料。不得把模型输出当作工程事实；每条产品主张、素材权利和审核记录都必须可追溯。当前 MVP1 初始渠道使用 [ADR 0002](../decisions/0002-camofox-facebook-personal-profile-mvp1.md) 已批准的受控 Facebook Personal Profile，成片 Gate 01 后仍需管理员独立逐帖确认。该受控渠道的决定不代表其他平台、账号或 API 已通过验收。

## 保留期与责任

[ADR 0007](../decisions/0007-marketing-video-release-policy.md) 和[版本 1.0.0 政策](../../config/marketing-video-release-policy.json) 已接受：视频工作副本、提示词、处理输出与成片按各对象首次创建时间保留 90 天，`coda` 负责访问、事实／权利审核、逐帖发布确认及渲染额度。外部视频生成保持关闭、预算为 0；既有剪辑和渲染仍消耗获授权云服务额度。

应用已按创建时间执行截止检查：到期停止读取、编辑、复制、审核、处理及新发布；每小时受认证的维护入口分批清理视频正文和符合条件的私有工作素材，失败可重试。原始工厂证据和来源／权利引用受保护，外部平台副本不属于自动清理范围。[应用实现核查](reports/m2-retention-enforcement-20261009.md)与[生产及托管副本盘点](reports/m2-retention-operations-20261009.md)记录各自证据和限制，#122 继续跟踪未验收项。

维护响应的 `videosPurged`、`objectsPurged`、`protected`、`failed` 是聚合计数，不能向调用方返回私有路径或正文。非零失败返回 503；排查身份与密钥配置、数据库及存储可用性、受保护引用或异常路径后，沿原清理记录重试。不要通过刷新创建时间、关闭访问门禁或扩大路径白名单使维护“通过”。

生产核对须分别取得迁移版本、READY 部署来源、正式域名、维护任务登记及请求结果；任务登记和手动执行不能冒充定时调用。当前没有到期对象时保留零结果，不能改写真实资料时间制造删除验收。上线前的原始证据与 Ready 产品摘要用于核对误删或误写；实际到期 Blob 删除仍须以实际对象和存储回执另行验证。

恢复数据库、部署或快照后，先核对当前政策与迁移、按原创建时间阻断已到期记录，再检查受控副本和清理队列；确认保留期边界后才开放使用。恢复旧副本不构成续期授权。模型服务、Workflow 历史回放、日志／导出和数据库备份的保留须逐项核对配置和可观察证据，不能从应用删除或关闭 SDK 遥测推导全部副本已经移除。不得关闭审计防篡改保护来清理历史自由文本。

## 剪辑／渲染故障与后续供应商路线

MVP1 当前只执行已有素材剪辑与合成；外部视频生成供应商仍被服务端默认拒绝。以下供应商恢复步骤仅适用于以后另外批准并启用的路线，不能据此启用供应商或增加预算。

1. 停止向故障模型提交新任务，并在能力登记中禁用该模型。
2. 保留任务、错误摘要和私有证据引用；不要把密钥、原始素材或客户数据写入日志或 Issue。
3. 只对处于 queued 状态且未耗尽尝试配额的合成或已授权任务重试。
4. 若要切换模型，重新核对能力、画幅、时长、分辨率和当前验证证据；重新进入人工审核。

## 账号授权失效

当前受控 Facebook 账号失效时，停止该渠道的发布及观察，按现有浏览器恢复契约处理；登录恢复不会自动解除业务暂停。对于以后已独立批准的官方 OAuth 通道，使用以下步骤：

1. 停止该渠道的发布与草稿提交，保留导出文件和审核轨迹。
2. 由账号管理员在官方渠道重新授权，确认 scopes、账号归属和有效期。
3. 用非生产测试素材验证回调与权限后，记录新的验证证据；不可复用旧 token。
4. 恢复前由人工确认目标渠道和账号，任何自动重发都必须显式批准。

## 导出失败

1. 记录导出 preset、容器、编解码器、尺寸、帧率、时长和失败原因。
2. 区分私有项目导出预设与平台接收资格：预设校验通过只允许受控导出，平台／账号接收仍须独立验证；不能把猜测的参数报告成官方规格通过。
3. 修复后从已批准的视频计划重新导出，并复核字幕素材与权利证据。
4. 使用当前 FFmpeg／ffprobe 成片测量及导出清单验证实际文件；清单的 `platformAcceptance.status = not_evaluated` 不能改写成平台接受或发布成功。

## 人工回滚

1. 立即停止后续提交，并在官方渠道撤回草稿或删除发布内容。
2. 将视频项目转入 revision_required，保留已发生的事件和人工决定，不改写历史。
3. 记录回滚原因和最小化的私有证据引用；涉及产品事实时重新执行 Gate 01。
4. 重新发布必须从人工审核开始，不能直接复用旧发布操作。
