# 工作区层级与交互一次性切换验收

关联：Decision #482、ADR 0008。验证仅使用明确标记的合成记录和隔离本地 PostgreSQL，不调用真实模型、不连接真实渠道、不发送业务消息。

## 变更契约

主导航为四类任务与资料；项目首页仅管理名称、成员和归档。记录地址与 ID 保持原样，但页面不再加载阶段分发、默认阶段、阶段待办或旧参数适配器。全局创建要求明确选项目，有效项目筛选和来源对象可直接创建。单条创建打开服务端返回的结果 ID，修订留在详情；目录批量导入仍显示结果清单。视频按需进入已有独立编辑器。

返回地址只接受任务页及三类资料清单的允许参数。详情读取指定授权对象，销售按已存 UUID 关系加载相邻需求、报价、客户和交期；名称或公司相同不会产生关联。失效／冲突关系保留可见提示，不能选择替代记录。

发布固定当前内容，使用各自原有领域传输服务和授权条件，逐帖确认最终文案、素材、账号与渠道。提交只表示排队或等待回执；未知结果、账户验证和暂停渠道继续失败闭合且不自动重试。旧 Facebook／浏览器管理页仅显示设置迁移链接。

## 一次性切换与回滚

在全部 CI 通过后 squash merge 并部署同一版本，不并行保留两套界面。上线前核对所有运行入口和通知都使用新地址；旧书签明确停用。出现应用回归时部署上一版本，不回滚业务数据。记录 ID、证据、审批、发布历史、成员关系与领域状态没有迁移，回滚后须核对切换期间新建记录仍可读取。

合成检查验证软件行为，不代表真实工厂事实、生产渠道资格、真实交期／报价正确性或真实用户满意度已验收。
