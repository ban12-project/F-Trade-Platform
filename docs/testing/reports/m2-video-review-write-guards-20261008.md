## 已验证的问题

基线为 main `f20b8f29224e72365cc9f6e65fd0a33cf83cc2bd`。在隔离 PostgreSQL 的合成数据上调用实际 `reviewMarketingVideoAction`，先持有视频记录行锁，再观察真实请求等待：撤销管理员角色或删除会话后释放锁，请求仍返回 success，视频从待审核 v1 变为已批准 v2，Gate 变为 approved。填写语法有效但不存在的证据引用也产生相同写入。

旧 `decideVideoReviewAction` / `decideVideoReview` 没有页面或组件调用，仍保留只传 actorId 的审核写入路径，缺少当前产品与导出记录保护；本次删除这条未使用的旧路径。

## 实现与边界

- Server Action 独立复用视频审核 Zod schema，领域函数再次解析输入，必须传入当前 actorId、sessionId、projectId。
- 获取视频、Gate、产品与素材锁后，重新确认活跃营销项目、当前编辑成员、项目拥有的 marketing_video 记录、当前管理员审核角色、未封禁账号及未过期会话。成员、所属链接、用户和会话保留共享锁至事务提交。
- 审核证据必须已持久化，且属于审核人或已被授权用于该项目。证据链接、Gate、成片审核状态、记录版本、流程事件和审计在同一事务提交；证据等待后再次核对会话自然过期。
- 保留当前 ProductReady 事实、ProductMedia 使用权、成片校验及私有测试素材禁止批准的既有保护。渲染与 AI 后台任务契约保持原有语义。
- 未知数据库、来源、媒体或凭据错误返回受控提示，不返回原始异常或数据库记录。

## 证据

隔离 PostgreSQL 的 65 个实际 Action 场景通过：正常批准/退回、审核人自有与项目共享证据、真实等待期间撤权、陈旧身份快照、无权/不存在证据、项目/视频/Gate/用户/会话/成员/所属链接/产品/证据锁等待期间自然过期、身份作用域错误、当前事实/导出/私有素材保护、授权保留至提交。失败场景比较完整视频、Gate、流程、审计、项目证据链接及项目更新时间，确认没有部分业务写入。

实际签名登录的 9 个浏览器场景通过，原有 7 个视频上下文场景通过。浏览器测试只使用合成导出契约，阻止私有预览媒体请求；没有调用云存储、模型、FFmpeg、Workflow 或真实发布。初次测试保留失败证据；后续增加输入值及按钮可用状态断言，并将自然过期设置移至实际锁等待后，避免 Better Auth 自动续期影响测试。

独立实际页面验证了缺失证据时的受控提示与输入保留、有效证据批准、产品事实保持不变。Next.js MCP 编译问题、运行错误为空，React DevTools 核对实际编辑组件状态。默认 TypeScript 7 CLI、完整仓库校验、Action 错误隐私检查均通过。两项新领域/Action 检查已纳入研发 CI；正式交付以本 PR 的提交、五项 CI、合并及生产部署记录为准。
