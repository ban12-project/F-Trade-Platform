## 指标与失败口径

机器摘要的修订与 RFQ 计数只取同一目录演示批次的数据库审计：产品修订 20、RFQ
补齐修订 20、报价修订 20，共 60 次；RFQ 总数与 Ready 均为 20。
事实错误与成功绕过门禁的零计数限于对应已执行断言及审阅，不包含未运行路径。
外部依赖阻塞为零仅针对该受控模拟链；它不表示生产登录、真实渠道或人工决策已完成。

A–D 初轮失败、后续单槽位重跑、早期 OCR 漏识别、导航超时及模型/CI 拒绝记录均保留。
#348 仅增加安全诊断及补测，不等于已经查明历史间歇失败的根因。
本轮没有真实对外消息；临时云文件清理分别见各报告。原始资料、模型正文、业务标识、
凭据及私有地址均不进入本汇总。
