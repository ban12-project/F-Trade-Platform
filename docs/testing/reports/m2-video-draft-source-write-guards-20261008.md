## 已验证的问题

基线为 main `dadc064c46b83efe6d1921e17e5d26fcf5f9ad37`。隔离 PostgreSQL 的实际 Action 复现显示，保存、复制、新建及 AI 任务提交在实际行锁等待期间撤销会话或封禁账号后仍可成功写入。复制时移除来源项目成员资格也未阻止复制。产品媒体使用权在等待期间自然过期仍可创建视频；上传读取期间撤销会话后仍可认领证据。

## 实现与边界

- 人工保存、复制、新建、素材认领、素材登记 / 审核及任务提交必须提供当前 actorId、sessionId、projectId。获取来源锁后重新确认当前活跃营销项目、记录归属或产品关联、当前成员、未封禁账号、应用权限与未过期会话；授权行保留至提交。
- 来源项目 viewer 可以复制可读剪辑稿，目标项目必须有编辑权限。复制保留事实与来源，生成独立草稿，清除预览与审核状态。
- 新建视频与初始 AI 队列、修改剪辑稿与合成队列分别在同一事务提交。后台已接受任务保留原有版本冲突、当前事实 / 媒体保护及项目归档规则。Workflow 启动失败如实显示已保存且可重试的任务状态。
- 产品媒体的新建资格和使用权期限按锁等待结束后的当前时间评估。素材审核重新确认管理员权限；来源、权利与审核证据必须已持久化且有权用于项目，人工媒体写入必须从拥有产品的项目发起，证据链接、素材决定与审计原子提交。产品退出 ProductReady 后仍可撤销危险素材。
- 上传先在锁外核验私有字节，再以一笔事务认领完整批次，失败不能部分认领。已在独立授权步骤完成的上传证据保留其出处，可供后续重试。互联网导入在持久化意图和证据绑定阶段分别复查当前身份；已确认储存成功、明确拒绝绑定的私有文件可清理，未知储存 / 提交结果保留待核对，不误删可能已提交的证据。
- Action 与上传授权接口返回受控提示，不向客户端返回原始数据库、媒体 URL、来源事实或凭据错误。互联网素材继续仅限私有测试，不增加工程事实或正式报价、交期。
