## 版本与环境

基线 `64b4163e77ebf1e9c7a073d9868f350996257ade`。Node 24.21.0、pnpm 12.3.4、PostgreSQL 17.10、Chromium 151.0.7922.34；依赖锁文件和 Next.js 编译配置未改变。数据库为本轮创建的本机合成集群，没有访问生产账号、真实资料或外部社交网站。

## 变更边界

- 所有者经现有工作区 Server Action 归档／重开；状态、权限与审计在同一事务处理。重复状态请求不重复追加审计。
- 项目业务写入与状态变更锁定同一项目行。产品、内容、销售、视频的创建、修改、审核、证据关联及工作流状态变更，在领域事务中检查当前状态；旧页面的预检不替代事务检查。
- 已归档项目的队列不取得新执行授权。未领取发布／回复和视频供应商任务从候选查询中排除；视频处理任务的入队、启动占位及实际领取重新检查归属。重开恢复资格，仍须通过原有权限、版本、有效期和人审契约；不复活过期任务，不重发未知结果。
- 已开始的外部执行可保存原任务结果及生命周期信息。发布回执仍校验原租约、授权、摘要、持久载荷和幂等性；人工核对保留原始 unknown 记录，不授予新发布权限。
- 归档不撤销成员，读取、私有预览／下载、目录历史和审计继续按原访问权限提供。成员管理仍需所有者权限。引用项目不拥有来源事实，归档引用项目不冻结来源项目。
- 既有未关联工作区的聚合保留原授权边界；使用已归档来源产品发起无项目内容／视频创建，也会拒绝。未新增公共 HTTP API 或验收摘要状态。

归档的并发界限是服务端事务内的执行授权。授权已经提交的外部尝试可能仍在飞行中；归档不声称能撤回浏览器中已经发出的点击或取消远端已经接收的渲染。此类尝试保留回执，未知结果继续人工调查。
