# 参考视频导入与修订验收记录

关联 #341、#26。初次导入因缺失回调失败；修复后实际模型剪辑、云端合成、修订、
私有预览和模拟审核下载通过。该结果不等于真实人工批准或外部平台验收。

## 执行边界

使用已授权参考 MOV 的本机 12 秒测试衍生片，3,701,465 字节。原始 MOV 不变；
该结果不覆盖数百 MB 原件的分片上传，也不证明 HDR 色彩转换质量。
关联产品来自同批目录草稿及明确的 MOCK 补充，不证明画面与真实 SKU 相符。
资料权利记录限定私有测试，不授予外部发布或真实产品关联的确认。

## 首次失败的可观察结果

- 初始开发环境没有固定视频镜像配置，旧 OIDC 已过期。刷新开发凭据后，读取项目已有
  私有镜像摘要，在拒绝网络访问的临时 Sandbox 中验证 FFmpeg、libass 字幕、libx264、
  AAC、ffprobe 与字体均可用；临时 Sandbox 已停止并删除。未更改线上环境配置。
- 本机运行时指定该固定镜像，再通过真实浏览器提交素材。私有 Blob 回读字节数和
  SHA-256 与本机衍生片完全一致。
- Blob SDK 警告无法为本机确定完成回调地址。回执保持 `issued`，创建 Action 返回
  “素材上传尚未完成”，数据库中没有视频聚合和处理任务。
- `claimCompletedVideoUploads` 只短暂等待回调，随后拒绝 `issued`；尚不能以服务端
  对精确私有路径的字节核验恢复这类成功上传。生产回调延迟或丢失的影响尚未实测。
- 失败记录保留。该临时云对象已删除，并以禁用缓存的私有读取确认不存在。

## 首次失败时的验收边界

#341 将覆盖缺失/迟到回调的服务端核验、权限与过期边界、并发领取和不完整对象拒绝。
修复后重新执行浏览器导入，再单独验证实际 AI 剪辑、Sandbox 合成、私有预览及模拟审核。
本次没有调用剪辑模型、产生新成片、批准视频或执行外部发布。


## 修复后的可观察结果

- 服务端可从 `issued` 回执恢复：只读取回执绑定的私有路径，核验 MIME、文件签名、
  精确字节数及 SHA-256；读取前后重新核验权限和有效期，以事务处理并发领取。
  迟到回调不能覆盖已领取回执，签名元数据不匹配时拒绝请求。
- PostgreSQL 合成回归覆盖缺失/迟到回调、并发领取、错误归属/权利、对象缺失、截断、
  类型/签名错误、超长流取消、过期、禁用账号、读取中撤销成员权限和项目归档。
  新回归及既有素材上传回归均通过；数据库夹具不含原始资料。
  TypeScript 校验和隔离工作目录中的 Next.js 生产构建通过。
- 真实浏览器重新上传同一 12 秒衍生片，创建 Action 仅 1,768 字节。
  回执成功领取，实际配置模型一次尝试生成剪辑稿；两次 Sandbox 合成均一次成功。
- 初版抽帧发现新增字幕与素材自带 TEST ONLY 水印重叠。通过浏览器执行模拟退回，
  删除两段新增字幕，保留原水印和中央 MOCK CTA，再合成修订版。
  修订版在 2 秒及 6.8 秒抽帧中未见原字幕重叠，标记清晰可读。
- 修订成片为 H.264/AAC、1080×1920、30 fps、7.633333 秒、1,892,206 字节。
  这只是所测衍生片的结果，不覆盖所有剪辑或输入格式。
- 私有预览：测试账号返回 200，未登录返回 403。通过独立 MOCK 审核证据执行模拟批准后，
  MP4 与导出清单下载均为登录 200、未登录 403；下载 MP4 与修订预览逐字节一致。
  导出清单显示 `reviewStatus=approved`、项目预设校验通过，平台接受状态仍为
  `not_evaluated`。本次没有真实人工批准，也没有发送或发布到外部平台。
- 验证完成后删除重新上传的 1 个输入对象及 2 个生成成片，逐个禁用缓存读取确认不存在；
  首次失败的已删除对象仍不存在。保留本地审核/任务记录和本地测试成片用于审计，
  因云对象已清理，这些测试记录不再提供可用云端预览。
