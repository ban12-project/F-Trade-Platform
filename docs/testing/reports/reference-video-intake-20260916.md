## 可观察结果

- 初始开发环境没有固定视频镜像配置，旧 OIDC 已过期。刷新开发凭据后，读取项目已有
  私有镜像摘要，在拒绝网络访问的临时 Sandbox 中验证 FFmpeg、libass 字幕、libx264、
  AAC、ffprobe 与字体均可用；临时 Sandbox 已停止并删除。未更改线上环境配置。
- 本机运行时指定该固定镜像，再通过真实浏览器提交素材。私有 Blob 回读字节数和
  SHA-256 与本机衍生片完全一致。
- Blob SDK 警告无法为本机确定完成回调地址。回执保持 `issued`，创建 Action 返回
  “素材上传尚未完成”，数据库中没有视频聚合和处理任务。
- `claimCompletedVideoUploads` 只短暂等待回调，随后拒绝 `issued`；尚不能以服务端
  对精确私有路径的字节核验恢复这类成功上传。生产回调延迟或丢失的影响尚未实测。
- 失败记录保留。该临时云对象已删除，并以禁用缓存的私有读取确认不存在。
