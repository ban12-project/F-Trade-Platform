# M1 单产品导入当前权限验收（2026-10-07）

关联研发风险：[#542](https://github.com/ban12-project/F-Trade-Platform/issues/542)，M1 产品数据闭环。

## 缺陷与修复

单产品非流式导入原先只在 Action 开始时确认登录及产品写入权限，模型完成后的领域写入没有重新验证。隔离 PostgreSQL 调用实际 Action、AI SDK 和来源位置验证后复现：生成期间撤销登录、禁用账号、移除产品权限或让登录到期，仍创建产品、待审核 Gate 和创建审计；普通业务员正常导入对照成功。失败复现记录保留。

Action 现在必须绑定明确的营销项目，并在取得模型凭据前查询当前登录、账号角色、禁用状态、项目状态及成员编辑权限。模型完成后的公开领域写入函数必须提供登录身份，在保存事务内再次锁定账号、登录和项目，复查同一权限；登录到期使用取得全部授权锁之后的时间。失效时拒绝产品、项目关联、图片、Gate、工作流和创建审计，返回固定安全提示。正常结果继续进入 `PRODUCT_REVIEW_REQUIRED`，Gate 01 保持 pending。

## 验证

- 实际 Action／SDK／来源约束／PostgreSQL 回归：普通业务员、管理员和生成期间管理员降为仍有写入权限的业务员均成功，仅保存待审核草稿。
- 八种生成期间变化均拒绝全部上述创建写入：登录撤销、账号禁用、产品权限移除、登录到期、成员降为只读、成员移除、项目归档、项目改为销售类型。同样八种初始失效状态即使认证传输返回旧快照，也在模型配置及模型调用前被拒绝。缺失、空值、无效及无权项目亦被拒绝。
- 直接领域写入拒绝登录与账号不匹配以及无效身份。模型编造事实仍被实际来源验证拒绝。等待账号锁、项目锁期间到期的两项回归通过：真实 PostgreSQL `pg_blocking_pids` 确认等待后才推进受控 Date；锁、事务及异步执行均真实。
- 上述回归仅替换 Next.js 请求适配、认证传输及外部模型配置／提供方；权限函数、SDK、来源验证及持久化真实执行，禁止远程请求。追加审计保留。
- 两项认证 Chromium 浏览器测试通过：签名登录、真实表单、Action、SDK、已保存证据和数据库写入；仅模型使用隔离的本地 HTTP 提供方。普通 editor 正常创建待审核记录；模型返回前调用实际成员管理函数降为 viewer，拒绝创建，来源引用和文本保留，按钮恢复，成员变更审计存在。
- 本地页面另核对初始失效的固定提示、资料保留及 React 输入绑定／提交渲染。观察工具对整个组件的 Hook 检查曾产生 `ReactDebugToolsRenderError`，记录保留；组件输入检查成功。使用新观察会话重复实际提交后，Next.js 当前配置和运行错误为空，全部路由编译问题为空。最初手工引用不满足既有 `source-`／`evidence-` 格式，改为合法合成引用后再验证。观察登录及模型配置按归属撤销，审计夹具保留。
- 默认 TypeScript、格式和完整干净追踪快照的仓库校验通过。固定错误隐私测试拒绝伪造错误代码，变更原始异常消息及 cause 不影响允许展示的提示。第一次浏览器测试类型检查的夹具关联字段错误已更正；最后一次数据库复查的本地连接账号错误已更正，失败日志均保留。新增权限回归纳入 CI；最终提交 CI 和生产部署核对结果记录在 PR。
