## 已验证问题与修复

真实 `createContentDraftAction` 在初始身份检查后等待 ProductReady 记录锁。观察实际 PostgreSQL 锁等待后，删除会话、封禁账号或令会话过期，修复前均仍创建内容草稿、pending Gate、工作流和审计，预期零创建断言失败。修复后同一探针的三种失效均拒绝，新增内容为零；正常对照继续成功。前后原始结果及合成追加审计保留，不覆盖失败。

手工创建必须携带当前 actor/session/project 身份。事务取得项目及来源产品锁后，再检查当前营销项目、编辑权限、账号封禁、`content:write`、会话归属及自然到期。授权锁持续至事务完成，创建时间使用等待后当前时间；写入仍只创建待审核第 1 版，产品事实、证据和 ProductReady 来源保持原样。

正常业务员与管理员都有 `content:write`，管理员降为业务员不等于丧失写权限。本次正向及在途测试分别覆盖这两类合法写入者；无效角色作为拒绝对照。未将内容编辑提高为管理员专属权限。

Action 继续独立复用 Zod 表单校验，只返回最小成功结果或受控提示。未知异常、数据库信息和私有来源不显示；工程事实视觉说明拒绝使用固定提示，避免原始匹配值进入错误消息。现有草稿表单无 UI 改动，保存失败不重置输入。
