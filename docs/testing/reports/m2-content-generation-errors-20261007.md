# M2 内容生成错误边界验收（2026-10-07）

关联研发风险：#534，M2 内容发布闭环。范围为 AI 内容初稿生成失败时的客户端状态与重试。

## 已确认缺陷与修复

原 `generateContentDraftAction` 将模型配置、连接和生成异常交给 `actionError`，任意 `Error.message` 会作为编辑者可见的提示。隔离 PostgreSQL 回归确认配置错误原文被回传；真实认证浏览器经生产 Action 和已安装 AI SDK 请求本地 MOCK 服务，401 错误中的 MOCK 私有标记同样出现在实际客户端响应中。没有真实供应商请求，也未检查或声称生产凭据曾泄漏。

模型配置读取、模型初始化、供应商调用和生成结果校验现在使用独立异常边界，统一返回失败、重试／手动填写和联系管理员的提示。不返回或记录异常原文、嵌套原因、响应、地址、请求正文或凭据。授权、输入校验和生成期间权限／事实变化的受控提示继续独立处理；成功初稿仍需人工核对后创建待审内容。

## 验证证据

- 真实 Action／Zod／PostgreSQL 回归覆盖配置错误、模型初始化错误、实际 SDK `APICallError`、结构化输出错误、生成校验错误及对象／字符串／null 拒绝值，共 8 类。完整客户端状态均无 MOCK 私有标记或地址，失败不返回初稿，显式重试成功。
- 既有 15 种调用前拒绝继续在读取配置和请求模型之前生效；合法 owner/editor 只使用授权产品事实；6 种生成期间会话、成员、归档、停用、Ready 或事实变化仍丢弃结果。
- 新增认证数据库浏览器测试保留真实身份、普通 editor 项目成员权限、Server Action、AI SDK、输出 schema 和 PostgreSQL，仅供应商为本地 HTTP 替身。401 与缺字段的结构化响应均得到安全提示；检查实际客户端响应、可见页面及浏览器日志均无私有标记。等待期间的人工正文修改在失败后保留，重试成功，未创建业务内容记录。默认模型配置恢复，会话撤销。
- 首轮 CI 的 270 项页面及原有 51 项认证数据库检查通过；新增探针读取 Flight 响应时遇到 Chromium `Network.getResponseBody` 的资源已回收错误。探针改为读取原请求的真实上游响应并原样转发，继续断言全部响应内容，不替换 Action 结果、不移除隐私断言。首轮失败保留，最终提交重新执行完整 CI。
- 已编译页面的 14 项既有回归通过，覆盖五个草稿字段的人工编辑保护、生成上下文变化、失败重试、生成／提交互斥及来源回查。该组替换 Action 响应，与上述实际 Action／SDK 浏览器验证分开记录。
- TypeScript 校验和格式检查通过；Next.js 自检与 React DevTools 用于运行中表单核对。既有 PostgreSQL CI 作业自动执行扩展回归，新增浏览器测试由认证数据库 CI 执行；最终提交的完整 CI 及部署状态在 PR 交付记录核对。
