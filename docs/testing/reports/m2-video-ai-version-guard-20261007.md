# M2 视频 AI 初稿版本保护验收（2026-10-07）

关联研发风险：#538，M2 内容发布闭环。范围为后台 AI 初稿覆盖较新人工草稿的冲突保护。

## 已确认缺陷与修复

实际工作流入口在读取视频后等待模型结果，完成时只检查当前编辑状态、素材引用和权限，没有比较草稿版本。隔离 PostgreSQL 已复现：版本 1 开始生成；另一位有权限的编辑者实际保存新 CTA 和片段时长，版本变为 2；旧 AI 结果覆盖人工草稿，版本变为 3，任务仍显示成功。原复现及新增回归的人工草稿保留断言均失败，记录保留。

生成快照现在携带视频聚合版本。专用 AI 保存入口验证版本输入，沿用人工保存的领域校验，并在事务中重新确认项目编辑权限、取得视频行锁后比较版本。版本不同则不保存旧结果、不追加保存审计，任务记录固定的 `AI_DRAFT_STALE` 提示；终态版本变化允许用户主动重试。正常 AI 保存的审计增加生成依据版本，人工保存入口保持原有参数和行为。

## 验证证据

- 新增真实 PostgreSQL 回归调用实际工作流函数、候选编译器、产品事实／媒体运行时守卫、领域写入和追加审计。仅外部模型执行／配置与素材取样边界使用合成替身，禁止远程请求；直接调用工作流函数不等于验证持久化 Workflow 调度器或真实模型质量。
- 未变更快照正常保存；生成期间另一位普通用户实际保存的新 CTA 和片段时长完整保留，旧任务失败且不增加保存审计；显式重试创建新任务并正常成功。同一快照版本的两个并发 AI 保存仅一个提交。viewer、外部用户、归档项目和无效版本均拒绝且无草稿／审计写入。
- 认证数据库视频浏览器整组 7 项通过，包含既有 AI／渲染失败及新增版本冲突提示，queued/running 期间锁定、失败后恢复、真实保存 Action 的等待保护、数据库文案／版本和刷新后持久化均验证。
- 第一次浏览器运行在等待定时刷新提交时失败；记录及 trace 保留。原等待只观察请求发出，开发环境编译延迟使旧响应仍在进行。改为等待真实刷新响应完成，再判断终态；没有关闭刷新、绕过真实 Action 或用固定延时伪造通过。
- 普通 user／项目 editor 在真实本地页面看到固定冲突提示，原草稿保留且编辑恢复。React DevTools 核对实际 `EditVideo` 及 CTA 状态渲染；Next.js 编译与运行自检无错误。独立观察夹具会话撤销，未保存的观察夹具清除，真实测试写入和不可删除审计保留。
- 默认 TypeScript、变更格式和干净追踪快照的完整仓库校验通过；失败信息隐私回归确认新代码仍不暴露原始消息或私有 URL。新增数据库回归纳入 CI，最终五项 CI 与部署结果在 PR 交付记录核对。

## 验收边界

本次受委托实现审核通过。全部产品、账号、项目、视频和任务均为标记的合成数据；无付费模型、生产业务写入或真实素材处理。没有改变业务 schema、数据库迁移、事实／素材授权、人工审核、发布门禁、Cache Components 或两个 React Compiler 配置；本报告不替代生产试点 Go。
