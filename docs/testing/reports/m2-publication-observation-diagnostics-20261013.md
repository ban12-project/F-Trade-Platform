# M2 发布观察分类 — 2026-10-13

对应 #603 / #156。新观察失败沿既有签名回执的 `failureCode` 字段保存固定分类：编辑器未关闭、身份／帖子未就绪、链接解析、导航／页面契约／响应、匹配歧义、视频或帖子未核实、审核到期、取消和请求超时。未识别异常仍使用旧的阶段 unknown；正文、账号、页面地址和异常原文均不拼入分类。

分类不改变发布结果：点击后的失败仍是 unknown，渠道暂停，不重复点击。旧 unknown 不迁移、不覆盖。UI 只呈现固定白名单标签。签名回归验证分类被签名绑定，数据库回归验证文字及视频 unknown 的分类持久化和重放行为。

本次使用当前已部署的执行器，通过原生 Camofox REST 接口对既有帖子执行只读观察，验证身份、完整配文、一个视频及规范 Reel 链接均匹配。未调用素材上传、发布授权、发布点击或回执写入；这项验证不证明新帖唯一性，也不还原原失败时刻的具体异常。私有原始结果留在受控工作记录，不进入 GitHub。

新的自动发布验收必须使用单独准备的已审核任务，并在展示完整发布摘要后取得新的逐帖授权。历史人工核对结果不是自动回执通过的证据。
