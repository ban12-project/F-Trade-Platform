# M2 内容修订与复制当前登录回归（2026-10-08）

本次处理 [#552](https://github.com/ban12-project/F-Trade-Platform/issues/552) 及完整旅程发现的 [#553](https://github.com/ban12-project/F-Trade-Platform/issues/553)。仅使用明确标记 SYNTHETIC 的产品来源、营销文本和持久化证据；不调用模型、云媒体或外部业务服务。

## 已验证问题与修复

真实修订和跨项目复制 Action 在初始身份检查后等待内容记录锁。观察实际 PostgreSQL 锁等待后，删除会话、封禁账号或令会话过期，修复前两种操作的六种组合均仍成功写入：修订从被拒绝的第 2 版进入待审第 3 版，复制新增独立草稿。零业务变更断言失败。修复后同一探针的六种组合均拒绝，完整业务快照保持原样；正常对照继续成功。前后原始结果和合成追加审计保留。

内部修订、复制函数强制当前 actor/session/project 身份。事务取得业务记录和 ProductReady 来源锁后，再检查当前营销项目编辑权限、账号封禁、`content:write`、会话归属和自然到期。修订另检查当前项目确实拥有该内容。复制在来源产品锁等待后重新确认并锁定来源项目读取成员资格，再做最终登录检查；来源只读成员仍可以复制到自己可编辑的营销项目。授权锁保持至事务完成，写入时间使用等待后的当前时间。

正常业务员与管理员都有 `content:write`，管理员降为业务员不等于丧失内容编辑权限。两类写入者均作为正向及在途对照。未将编辑权限提高为管理员专属。修订不更换来源产品，不支持或未经核验的事实字段仍拒绝；复制不修改源记录、产品事实或证据，不继承批准状态。

Action 独立复用 Zod 校验，只返回最小成功结果或受控提示。未知异常、数据库信息和私有来源不显示，含工程事实匹配值的视觉说明错误归一为固定提示。失败不刷新或重置现有表单与复制选项。

原有完整页面旅程另观察到未编辑的待审内容点击返回清单，被未保存确认阻断。原失败与浏览器轨迹保留。孤立四项导航对照在修复前通过，说明该现象存在时序条件，不能将初始字段归一的推断视为已验证根因。审核表单改为只有当前可审核、表单已修改且有决定/证据/备注输入时才登记未保存；空表单和只读状态可直接离开，真实已输入值仍受确认保护。审核默认保持未选择，未更改 Gate 校验或全局离开确认。

## 回归范围

- 真实 Action + PostgreSQL：两种操作分别覆盖管理员/业务员正常保存、两类合法写入者 × 六种锁等待期间失效（无效角色、会话删除、封禁、过期、项目编辑角色撤销、项目成员删除），内容、版本、Gate、工作流、审计、项目时间和关联整笔回滚。
- 四种初始认证快照失效分别在两种操作中拒绝；项目只读、非成员、归档、类型、缺失/错误项目、会话归属及直接空身份拒绝。
- 修订拒绝有效编辑身份指向无归属的其他项目、产品替换、不支持事实字段和重复待审保存；两项并发修订只有一项提交、一个新增 pending Gate 和修订审计。
- 复制允许来源只读成员 + 目标编辑成员，拒绝来源产品等待期间失去读取成员资格和同项目复制。来源产品已非 Ready 时，两种操作均零变更。
- 观察实际项目、内容、来源产品、账号、会话、内容归属及复制来源成员锁等待，再仅推进测试时钟到自然到期边界；修订六项、复制七项均零变更。当前授权事务完成前，角色撤销必须等待。
- 真实 Action 错误隐私、当前身份传递、受控业务提示及失败不刷新验证通过。
- 十二项真实签名页面验证覆盖两种操作 × 管理员/业务员正常保存及四种实际内容锁等待后的身份失效。正常保存进入待审详情，版本、七项文案和事实精确匹配，刷新后保留；失败保留七项修订输入、产品/事实或复制来源选项，完整数据库快照不变。禁止重试。
- 四项审核导航回归分别覆盖未填写直接返回，以及仅填写决定、证据、备注时取消离开保留输入、确认放弃后返回；全部版本、Gate、工作流、审计和证据保持原样。原七项内容审核真实页面回归继续执行。
- 首轮自动填写预填输入时焦点未稳定，复制选择器包含箭头装饰；原始失败保留。按实际控件先点击再清空/填写，并对提交前后输入及独立选择值精确断言，未弱化业务或数据库断言。锁等待扩展测试曾错误假设来源项目读取会锁项目行；按实际事务改为复制来源成员锁，并增加来源权限撤销回归，保留原始失败。
- 默认 TypeScript 7 CLI、完整仓库验证、原有产品到内容旅程和前两批内容审核/创建回归在交付前执行；CI 按本 PR 确切提交核对。
- `next-dev-loop` 使用正常开发服务、真实页面、Next MCP 与 React DevTools 核对修订和复制仍为待审状态；不启用测试 API，不重置运行中的 `.next`。
