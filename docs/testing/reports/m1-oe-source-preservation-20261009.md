# M1 OE 来源保留回归 — 2026-10-09

原 Issue #268/#5 的补充修复。已有验收口径只允许 OE 去除首尾空白并比较完整集合，原实现却折叠内部空白、统一大小写、剥去标点并接受子集。合法字面值可能被拒绝，改写或漏项也可能被接受。

## 修复及失败证据

- 字面 OE 集合保留大小写、内部空格和制表符、标点，仅按明确的逗号、分号或中文列表符分项。填入数组必须等于所引来源片段的完整集合，拒绝重复值。整个字段未填仍允许成为有缺失阻断的待审草稿。
- 使用服务端重建的所引片段，避免混用同文档不同产品的 OE。表格片段中的目录编号须与所选候选一致；即使相邻行有完整合法的 OE 集合，也不能借用。
- 标签提取只消耗同行的横向空白。空标签不能吞入下一行；兼容无冒号的旧标签格式时，不能将空标签的冒号当成 OE 值。此同行边界同时适用于其他明确标签事实。
- 提示词更新为 1.1.3，要求同样的逐字及完整集合行为；验证器仍独立拒绝不可信输出。

纯合成负向回归实际保存了修改前失败：合法混合大小写／内部双空格值被拒绝、相邻行完整集合未被拒绝、空标签借下一行未被拒绝；另保存内部制表符被误分项及空标签分隔符被当作值的失败。修复后，同一组回归通过。正向覆盖完整集合乱序及首尾空白、同行明确标签和旧无冒号标签。流式路径拒绝改写、子集和相邻行，接受完整合法集合；初始空流式草稿继续显示身份缺失。

可复现工程检查：`pnpm test:product-agent-evidence`、`pnpm test:product-stream`、`pnpm test:harbor`、`pnpm typecheck`，以及既有完整仓库和 CI 检查。合成标识符仅用于边界测试，不是工厂产品事实。
