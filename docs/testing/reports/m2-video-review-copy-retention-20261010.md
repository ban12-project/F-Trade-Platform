# M2 视频审核附件工作副本保留 — 2026-10-10

接续原 [#122](https://github.com/ban12-project/F-Trade-Platform/issues/122)。网关日志按用户决定继续排除于本次 M2 验收，状态保持未核验；本项仅修复应用内已声明的视频审核工作副本。

## 已证实缺口

只读生产核对发现，一份本次代理制作并由受邀账户上传的审核 CSV 包含当前剪辑／合成快照。该文件使用通用 uploaded:csv 来源标签，关联视频事实审核及通用文档上传回执。旧工作素材标签和清理条件均不包含它，不能因视频到期而清理。未在 GitHub 写入业务对象标识、原始文件、技术快照正文或凭据。

## 修复

上传者在视频工作台明确确认附件仅为本视频的审核工作副本后，服务端重新检查当前会话、审核权限、营销项目编辑权、视频所有关系、本人上传回执及既有审核引用。来源文件、产品图片、目录、素材／权利引用、非视频当前或历史事实用途及其他视频的审核附件均拒绝登记。

声明记录独立保存。原附件内容、摘要、创建时间、视频内容／版本和原审核决定不改写。截止时间取附件与原视频创建后 90 天的较早者，登记和重试不续期。声明及最小审计保留来源引用与摘要；已声明附件从工厂来源选项中移除，业务写入不能将它再用作事实或权利来源。

到期读取和写入拒绝使用工作副本。清理可删除已经声明且仍无来源保护的工作副本，即使通用上传回执与视频审核引用仍在。清理在实际锁等待后重新核对事实用途，继续保护原件。没有按通用 CSV 标签批量推断文件性质，也没有改写真实时间制造到期样本。
