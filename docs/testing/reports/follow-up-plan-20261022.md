# 内部跟进计划验证

关联 [#646](https://github.com/ban12-project/F-Trade-Platform/issues/646)，对应 MVP1 第 21–23 节的跟进节奏和规则评分。

原实现只能随发送回复更新跟进场景、评分和下次跟进时间，因此无渠道会话、暂停渠道或回复窗口外的销售记录无法单独排期。本次新增“保存跟进计划”：服务端重新授权项目成员、可编辑销售项目和 owned FOLLOW_UP 线索，仅更新计划字段与审计记录。清空时间可取消提醒，现有任务读模型显示保存后的排期。

发送仍使用原渠道、回复窗口、人工确认和交期 Gate 检查。保存计划不会写入消息、排队发送、批准交期或推进生命周期；已有发送引用与业务关联保留。输入时间由浏览器转换为带时区的 ISO 时间，服务器验证偏移并规范化为 UTC。
