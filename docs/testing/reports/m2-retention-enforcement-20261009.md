# M2 应用保留期执行核查（2026-10-09）

对应 Issue：[#122](https://github.com/ban12-project/F-Trade-Platform/issues/122)。业务决定沿用 [ADR 0007](../../decisions/0007-marketing-video-release-policy.md) 的 90 天及 coda 责任，不重新请求确认，不扩大逐帖发布授权。

## 执行范围

- 视频聚合承载的提示词、剪辑输出以视频首次创建时间到期；编辑、下载或复制过期内容不能续期。
- 私有合成／生成成片按资产创建时间到期；新合成资产绑定所属视频，视频先到期时也拒绝读取。历史未绑定资产仍按自身期限阻断，不猜测归属。
- 只清理精确营销工作标签且不存在来源／产品／权利／审核／非视频引用的证据。工厂原件不在范围内；异常存储路径拒绝删除并报告失败。
- 截止点立即阻断新读取／写入／审核／处理／发布；每小时维护负责后续删除，按批次与时间预算执行。删除回执或数据库提交回执丢失可重试，不在审计中复制正文或存储地址。
- Workflow 只持久化标识入参，步骤不返回营销正文；结构化生成显式关闭输入／输出遥测。历史追加审计、模型服务、日志和备份的保留仍待核验。未知发布结果保留暂停与人工调查；保留期到期不能授权重发。

## 验证

隔离 PostgreSQL 覆盖边界前／恰好到期／边界后，读取和批准／驳回拒绝，过期草稿保存／复制／启动拒绝，实际数据库锁等待期间自然到期，删除回执丢失后的重试，重复维护，原始来源与权利引用保护，以及清理等待后新提交的产品来源保护。另测私有上传跨期、清理锚点、不可覆盖重试和资产归属冲突。测试全部使用标记为模拟的资料，无外部发布、客户消息或模型请求。

维护接口缺少／错误密钥拒绝，调用者无法指定删除对象或路径，私有错误不回传，响应禁止缓存。既有项目隔离、审核、草稿、入库及发布核查由同一 PR 的 CI 回归。

生产上线前只读盘点：无超过 90 天的视频、成片或营销工作素材；现有旧版建议审核表无记录。上线后的迁移、来源版本、认证边界、首轮维护与工厂来源／已核验产品不变验证须记录交付检查点，不能仅凭预览构建标为生产通过。

## 尚未通过

受托管模型服务、日志、备份及历史追加审计中的受控副本尚未证明按期限移除。生产没有到期对象，故本次不声称验证了真实生产 Blob 删除；失败恢复与删除行为来自隔离契约测试。真实平台接收、逐帖发布与入站闭环不由本报告批准，M2 与 #122 保持相应未完成状态。
