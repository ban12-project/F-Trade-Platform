## 视频来源复核

当前目标仍是 ADR 0002 的 Facebook Personal Profile 浏览器路径。MVP1 仍仅剪辑有权利证据的既有素材，整条不超过 15 秒。

- [Meta 官方公告](https://about.fb.com/news/2025/06/making-it-easier-create-videos-facebook/)本轮正文可读；文章标注发布于 2025-06-17、更新于 2025-07-14。它宣布逐步将 Profile 和 Page 的新视频统一为 Reels，并调整受众确认流程。这不是目标账号已完成切换的证据。
- [Meta Facebook Postman 集合](https://www.postman.com/meta/facebook/folder/simabyk/reels-publishing)本轮重新取得正文，明确面向 Page 的 API 发布，并仍列 4–60 秒、9:16、至少 23 FPS。它不能作为 Personal Profile 浏览器的通用接受条件；9 月 26 日仅取得导航的记录保留。
- [个人主页 Reels 帮助页](https://www.facebook.com/help/www/2862139500770200)直接打开重定向到登录／临时阻止页。搜索缓存中的说明没有作为本轮已读取的规则正文。

新的[独立来源记录](meta-facebook-source-review-20261007.json)沿用现有契约，`ruleVersion: null`、`sourceApplicability: unverified`、`platformAcceptance: not_evaluated`。项目导出预设的 3–90 秒、MVP 剪辑的最多 15 秒、Page API 集合的 4–60 秒和统一发布公告分别属于不同范围；本轮未修改任何预设、发布适配器、受众或平台接受状态。下一次视频执行前须重新核对当前账号的实际创作流程、受众和自动回执观察契约，不能仅因官方公告可读就启用执行。
