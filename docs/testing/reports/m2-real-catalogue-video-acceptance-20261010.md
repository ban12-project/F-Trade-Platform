# M2 真实目录素材成片与受控下载验收 — 2026-10-10

接续原 [#122](https://github.com/ban12-project/F-Trade-Platform/issues/122)、[#126](https://github.com/ban12-project/F-Trade-Platform/issues/126) 和 [#156](https://github.com/ban12-project/F-Trade-Platform/issues/156)。在正式工作台完成一项真实来源目录图片的剪辑、合成、私有预览、本次委托审核和批准后下载。此项通过的是应用成片链路；目标 Facebook 账号的平台接收、自动视频回执和独立入站仍未通过。

## 实际输入与审核边界

使用真实来源项目中一项当前 `PRODUCT_READY` 产品及其已批准目录产品图，沿用[产品媒体验收](catalog-product-media-acceptance-20261009.md)的来源和权利记录。没有把 MOCK 项目旧成片改成真实素材，也没有使用车间画面来证明某个 SKU。当前私有媒体登记允许剪辑和公开分发，未授予生成式视频或付费广告权限。

正常生产页面复用该产品媒体，选择当前有证据的产品编号。AI 初稿生成一次后，Agent 在编辑器把创意字幕改为来源产品编号，并将末尾文字改为目录参考图片说明；保存后发起一次合成。成片只有目录图、当前核验产品名称／编号和普通营销排版；不包含 OE、尺寸、车型适配、认证、性能、库存、报价或交期声明，没有新增音乐、配音或生成产品外观。

审核主体为当前认证的 `coda`，执行者为本次用户委托的 Agent。逐文件摘要、来源／权利引用、人工修订过程和审核范围保存为项目内 `restricted` 证据，并核对完整私有回读。应用默认审核备注沿用“成片已人工确认”，其证据明确记录 Agent 执行，不能据此声称独立工厂签章或第三方许可证。成片审核不授权任何一条具体外部发布。
