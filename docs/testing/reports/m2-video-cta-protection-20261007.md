# M2 视频 CTA 编辑保护验收（2026-10-07）

关联研发风险：#536，M2 内容发布闭环。范围为视频后台处理和提交操作期间的 CTA 编辑保护。

## 已确认缺陷与修复

原编辑器在后台任务排队／运行时锁定片段编辑和保存按钮，但“最后两秒 CTA”仍可填写。真实认证浏览器与隔离 PostgreSQL 已复现：合成 queued 任务期间输入新 CTA，定时刷新后恢复旧文案；新增回归在修复前也确认 CTA 仍为 enabled，违反预期保护。原复现与失败记录保留。

现有 shadcn/ui Input 现在沿用片段编辑的同一等待状态：正在提交操作或后台任务 queued/running 时禁用 CTA。任务结束后恢复编辑，异步保存期间继续保护输入。没有新增基础控件、手工维护等待状态或改变业务契约。

## 验证证据

- 扩展认证数据库浏览器回归使用真实身份、普通 user／项目 editor 权限、Server Action 和 PostgreSQL；分别验证 `ai_draft`、`render` 两类任务的排队及运行保护，并观察真实定时刷新。任务状态由合成夹具控制，没有启动 Workflow、模型或媒体处理。
- 两类任务经现有失败记录函数结束后，CTA 与重试控件恢复可用。输入新文案，经真实保存 Action 写入，暂缓原响应以观察 React pending 状态，CTA 保持禁用；原样转发响应后恢复可编辑。数据库文案及版本均正确，重新加载后保留。
- 新回归的交互断言首次通过后，静态夹具清理因真实保存产生的审计外键而失败。按既有复制测试约定保留真实写入及不可删除的审计记录，撤销失败夹具会话，修正后整组 7 项认证数据库视频回归通过。没有删除审计记录或覆盖首次失败。
- 现有 8 项已编译视频页面回归通过，覆盖专用编辑器、时长、核验字幕、未保存导航保护、私有下载及只读审核。运行中组件由 React DevTools 组件树及 CTA 编辑的渲染记录核对，Next.js 自检用于编译和运行状态核对。
- 默认 TypeScript 与变更文件格式校验通过；保留 Cache Components、两个 React Compiler 配置和运行中的 `.next` 缓存。最终提交的完整 CI 及部署状态在 PR 交付记录中核对。

## 验收边界

本次受委托审核通过此实现缺口。全部账号、产品、视频和处理任务均为合成测试数据，没有付费模型请求或生产业务写入。验证 UI 状态及真实保存不等于真实模型、媒体处理、工厂事实或生产试点 Go 已完成；原有事实、素材权利、人工审核和发布门禁继续适用。
