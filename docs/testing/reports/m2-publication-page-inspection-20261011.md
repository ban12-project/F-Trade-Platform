# M2 当前发布页面只读核对 — 2026-10-11

接续原 [#156](https://github.com/ban12-project/F-Trade-Platform/issues/156)。此前已有实际账号／出口核验和登录 ready，但工作台只能查看云端状态，私有页面候选配置过期后缺少受控核对入口。新增管理界面与服务端检查边界，读取本任务创建的 Facebook 页面，帮助重新审核当前控件。

## 边界

Server Action 独立校验身份、管理权限和共享 Zod 输入。领域层核对当前数据库会话、节点归属、同一会话发起的运行中交互任务、租约和截止时间；仅支持具名持久托管 Sandbox。通过 provider 无恢复读取确认归属和 running，再由 provider 域名与当前节点源逐项匹配，限制到同一 vercel.run 服务。浏览器入口、选择器和脚本均不能由请求指定。

一次性接管票据从正常所有者边界签发，节点同源入口重新消耗并验证当前授权。固定只读程序使用本任务的受控 Facebook tab；中立出口检查 tab 保持独立，不借用账号其他页。节点要求当前出口检查有效，执行前后复查租约和停止状态。最终返回前再核对数据库会话、角色、节点／任务及观察时限。

候选配置从管理员私有固定文件读取，拒绝宽松权限、symlink、重复范围、超限和非法字段。过期候选仅作为待复核输入；原字节、摘要和日期保持，未转成当前发布权限。页面程序只读取当前身份、可见编辑器及控件数量；身份未匹配时不继续读取其他控件，Messenger 路径拒绝。隐藏媒体输入可以计数，但没有点击、输入、导航、上传或网络读取操作。

响应限 8 KiB，投影固定布尔／计数和配置摘要，拒绝超限及异常结构；不返回正文、账号值、页面 URL、HTML、选择器、Cookie 或凭据。最小审计保存观察时间、摘要和计数，不能当作事实／素材批准或外部回执。审计写入等待后再次核对时间，过期则整笔回滚。

## 验证

- 原生 Node 24 离线 Agent 包及缺失固定资产的负控通过；不引入应用依赖到运行镜像。
- 4 个新节点服务场景通过，覆盖私有过期候选不改写、固定 task tab、最小响应投影、失效／恶意响应、同源一次性票据及晚停止；与原有节点／出口回归共 43 项通过。
- 独立 loopback PostgreSQL 17：22 个授权、归属、来源、迟到撤权／过期、响应隐私及审计锁等待回滚场景通过，实际签发所有者票据。禁止外部 I/O，输入均明确标记合成。
- Action 认证、严格输入、服务端可信身份、错误隐私及不启动 Workflow 的隔离回归通过。
- TypeScript 7 与 Biome 错误级检查通过。Next.js 16.3.8 默认 Turbopack 运行、本地界面及 /_next/mcp 观察通过；未登录请求显示受控错误，候选过期保持明确。测试环境使用独立合成凭据和数据库，没有读取生产配置。
- 浏览器 CI 增加固定程序不改写页面／不泄露正文、隐藏媒体输入、身份阻断、Messenger 拒绝和界面认证检查。合成页面不代表实际 Facebook 页面范围有效。

## 部署与实际验收

本功能需要新 Agent 镜像；应用上线不能证明旧节点具有新入口。必须核对合并提交的镜像修订、受测镜像摘要、生产镜像固定配置、同一持久 Sandbox／profile、实际节点检查及资源退役。更新镜像不自动扩大 manifest.publish/inbox/login 或私有 publication.json 的日期和范围。

合并后的同一 Issue 回执补充生产部署、当前只读检查及尚缺控件；本报告不会把未执行写成通过。实际媒体上传、视频页面变化、逐帖授权、单次投递和可归因的自动回执仍分别验收；独立入站按用户决定暂缓。其他 M2 条件及网关日志范围排除沿用此前决定。
