# M1 Gate 01 当前审核权限验收（2026-10-07）

关联研发风险：[#544](https://github.com/ban12-project/F-Trade-Platform/issues/544)、[#545](https://github.com/ban12-project/F-Trade-Platform/issues/545)，M1 产品数据闭环。

## 缺陷与修复

实际 Gate 01 Action、身份授权函数和 PostgreSQL 复现：授权审核者提交后等待产品锁，此时移除审核角色、撤销登录、禁用账号或令登录到期，仍批准产品、递增版本并写入审核审计。完整合成事实和正常管理员／项目 editor 对照成功；四项拒绝断言失败的原始记录保留。没有将旧认证快照视为当前授权。

审核领域入口现在必须提供审核者、登录及所属项目。取得项目、生成任务、产品及 Gate 业务锁后，重新验证同一登录归属、到期时间、禁用状态、当前 `product:review` 权限、营销项目和 owned 产品关联；授权记录锁保持至事务结束。证据校验和关联从 Action 外部移入同一审核事务，关联操作等待结束后再次检查到期时间。失败时整笔回滚，产品事实、版本、Gate、工作流、审计和证据关联保持原样。原有逐字段事实来源、图片确认、当前版本和当前审核请求约束保留。

Action 只返回固定权限提示或允许展示的审核指引，未知异常、SQL、来源地址和原始产品值不返回客户端。手工页面复核另发现决定 Select 首次选择的 uncontrolled → controlled 告警；使用已有 shadcn／Base UI 的受控空值 `null`，仍不默认批准或退回。

## 验证

- 实际 Action／授权／领域写入／PostgreSQL：正常管理员、项目 editor 的批准与退回通过，事实和逐字段证据保持一致，版本、Gate、工作流和审计与决定一致。
- 八项提交期间拒绝回归：批准及退回分别覆盖角色移除、登录撤销、禁用和到期。先由真实 `pg_blocking_pids` 确认 Action 等待产品锁，再修改当前数据库授权；整笔审核及新决定证据关联零变更。
- 四项初始失效状态即使认证传输返回旧快照仍被数据库拒绝。业务员、viewer、非成员、已归档、销售类型、缺失／空／无效／无权项目、身份不匹配和无 owned 关联均拒绝。
- 七项自然到期回归：分别观察项目、产品、Gate、账号、登录、owned 项目关联、决定证据行的真实锁等待后推进 Date；事务、异步执行和数据库锁真实，均回滚。额外验证另一连接移除角色必须等授权事务结束。
- 六项真实签名登录 Chromium 测试通过：正常批准、退回以及上述四类提交期间失效。实际表单、Action 和 PostgreSQL；失效提示显示，决定、审核证据和备注保留，按钮恢复，完整审核快照不变。初始必须明确选择决定，组件状态告警为空。
- 原有 PostgreSQL 图片私有预览／归属／摘要／明确确认／退回／无图回归、逐字段修订并发／证据位置／图片 Gate、归档／重开／并发写入回归通过。增量流式持久化及 20 个明确标记的 mock 产品实际持久化、来源、项目关联和审核审计通过，旧版本／并发／缺证据决定仍原子失败。
- 实际 Action 错误隐私回归通过：伪造错误名称／代码、修改权限异常 message／cause、来源值等不泄露；保留版本冲突和图片确认提示；缺失项目和初始无权不调用领域写入。新增两项安全脚本纳入默认 TypeScript 7 CLI 和 CI。
- 最初浏览器失败是状态重复匹配、退回备注标签带必填、Spinner 改变按钮名称，以及 Select 图标包含额外文字；按实际区域、备注 ID、等待按钮和选择值收窄定位，未提高超时、重试或削弱数据库断言。失败报告和 trace 均保留。开发期间默认类型校验两次遇到 Next.js 正在生成的 routes.d.ts 暂时不可用，等待编译稳定后通过；没有删除开发输出或关闭检查。
- 手工实际登录页面验证批准与退回选择、权限失效提示、备注保留、React 输入绑定和提交渲染。首次 Next.js 运行告警保留，修复后新观察会话的配置／运行错误和全路由编译问题均为空；审核版本仍为 1、Gate 为 pending。观察登录按归属撤销，追加审计保留。
- 浏览器告警检查最初使用 ES2018 的正则标志，被既有 ES2017 目标的默认 TypeScript 校验拒绝；改为等价兼容模式，未改变目标或关闭校验。下载的官方组件示例仅作为私有文本保存。
- 本地默认 TypeScript 7、格式及完整干净追踪快照仓库校验通过。最终提交 CI 和生产部署结果记录在 PR。

## 验收边界

本次委托实现审核覆盖上述合成研发回归。没有真实工厂事实、模型调用、云存储或生产业务写入；Gate 01 仍由有权限的人明确审核，不能由 AI 补工程事实。本次实现验收不替代正式生产试点 Go。
