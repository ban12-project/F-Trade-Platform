# Node 26 LTS upgrade

Issue #815. Latest verified release on 2026-11-02: [Node 26.13.0 Lithium LTS](https://github.com/nodejs/node/releases/tag/v26.13.0).

Application engines require >=26.13.0 <27. Local selection, Actions setup and owned application/Agent/evaluation images use 26.13.0. The VPS image copies Node into a separate media base and now explicitly installs libatomic1, required by official Linux binaries since Node 25. The independent browser launcher remains on Node 22; this change does not establish its compatibility with Node 26. Actions' embedded runtimes remain independent of setup-node.

Verified locally with Node v26.13.0 and pnpm 12.3.4:

- `pnpm install --frozen-lockfile`
- `pnpm typecheck`
- `pnpm build` (Biome, Remotion bundle, default Turbopack production build and static generation)
- `node scripts/test-browser-agent-payload.mjs`, including missing-asset negative control
- `pnpm test:workflow`
- `pnpm test:harbor` (11 Python tests and 20 frozen synthetic expectations)
- `pnpm test:vps-compute`
- `git diff --check`

The first Agent payload run exposed its Node 24 assertion; updated to 26 and rerun successfully. No dependency versions or lockfile changed. Cache Components, React Compiler settings and TypeScript CLI checks remain enabled.

Limitations: Docker is unavailable locally, so container builds and Linux shared-library loading are not locally verified. Production deployment and authenticated browser acceptance are not claimed. General automatic CI remains temporarily paused under #711; image/release validation and automatic deployment remain enabled.

Creative review does not apply: infrastructure/version changes only, with no marketing content, prompts or engineering-fact changes.
