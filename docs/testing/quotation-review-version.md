# 报价审核版本绑定

关联 #301、#26。所有浏览器数据与商业条款为隔离 PostgreSQL 中的纯合成测试记录。

基线 `93f1915` 复现：一个会话保留单价 12.50 的审核页面，另一个会话退回报价、
修订单价为 13.25 并再次送审。旧页面提交批准后 Server Action 返回成功，未拒绝旧条款。
执行：https://github.com/ban12-project/F-Trade-Platform/actions/runs/33960305579 。

审核请求现在携带页面展示的 `reviewedVersion` 和 `approvalId`，共享输入 schema
拒绝缺失或非法值。服务端保持项目访问校验，并在锁定报价后、任何写入前核对版本与
当前待审请求。表单随记录、版本、审批请求变化重建。

双会话回归确认旧页面被拒绝；独立提交正确版本与错误审批 ID 也被拒绝。两次拒绝后
报价、审批、工作流事件和审计均不变。当前页面仍可批准修订后的价格，留下正确的
审批 ID、版本和证据。旧客户端缺少新字段时需刷新页面再提交。

本测试没有执行外部报价发送，也不代表真实商业条款已获确认。
